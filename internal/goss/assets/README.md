Official, unmodified Goss v0.4.9 Linux binaries and upstream SHA-256 sidecars.

Source: https://github.com/goss-org/goss/releases/tag/v0.4.9
License: Apache-2.0; see LICENSE.goss.

Both architectures are embedded in each ReadySpec executable. Digests are also
pinned in the Go source; replacing a binary and its sidecar cannot bypass the
startup integrity check. ReadySpec never downloads Goss at runtime.
